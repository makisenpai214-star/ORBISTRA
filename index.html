About

ORBISTRA v1.0 — map data & imagery © Google. Search, directions and tiles use the Google Maps Platform under your own API key. No imagery is copied or cached.

Connect Google Maps

ORBISTRA needs your own Google Maps Platform API key. It is stored only in this browser.

  1. Create a project at console.cloud.google.com and enable billing.
  2. Enable Maps JavaScript API, Geocoding API, Directions API.
  3. Create an API key and restrict it to your website domain (HTTP referrers).
